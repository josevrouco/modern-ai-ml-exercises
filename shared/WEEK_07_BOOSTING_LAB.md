## Learning sequence

1. Calculate one residual-correction step by hand.
2. Connect the calculation to the gradient-boosting update.
3. Build a compact booster from residual corrections and compare it with scikit-learn.
4. Compare logistic regression, one decision tree, Random Forest, histogram gradient boosting, XGBoost, and LightGBM under one validation design.
5. Define log loss, PR-AUC, and Brier score before using them.
6. Change learning rate, number of leaves, tree depth, and minimum leaf support one at a time.
7. Record a prediction, validation result, and keep/reject/follow-up decision for each run.
8. Select a model using probability quality, stability, runtime, calibration, capacity, and a business guardrail.

## In-class evidence

- Completed residual table
- Short explanation of the learning-rate effect
- Completed hypothesis/result/decision table
- Four-line model recommendation with exact configuration
- Individual retrieval response

The lab uses a simulated customer-retention setting so that it does not expose or complete the BookingGuard take-home analysis.
