# Week 8 · Support Vector Machines

## In-class SVM workbook

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/lathrahul/modern-ai-ml-exercises/blob/main/week-08/Week08_InClass_SVM_Workbook.ipynb)

1. Open the workbook with the badge above.
2. In Colab, choose **File › Save a copy in Drive** and work in your copy.
3. Run **Setup**, then work top to bottom. Cells marked ✏️ TASK are the ones you edit.

All data in the workbook is simulated, so no data files are needed.
