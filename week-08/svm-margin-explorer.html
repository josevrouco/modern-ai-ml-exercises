Five things to try

  1. Which points matter? On Separable, choose Remove point and delete a customer far from the street. Then delete a ringed one. Only the second moves the boundary. Workbook Part B
  2. What does C trade? On Overlap with the linear kernel, slide C from 0.001 to 1000. Watch the street narrow and the support-vector count fall. Task 2
  3. Why scale? On Spend vs sessions, untick Standardize. Distance is now measured almost entirely in dollars, and the model stops using app sessions. Task 3
  4. When is a line not enough? On Rings, compare the linear and RBF kernels. Part E
  5. How far does each point reach? On Moons with the RBF kernel, move γ from 0.01 to 100. Training accuracy keeps rising; ask whether the boundary would hold on new customers. Task 4

Simulated data. The solver uses sequential minimal optimization (SMO), the family of algorithm behind scikit-learn's SVC, with the same tolerance of 0.001; on test datasets it reproduces SVC's support vectors and decision values. Training accuracy is shown on purpose: it is the number that can mislead you.
