# Optional Quantitative Track

This is an ungraded self-study area for students who want more mathematics and additional practice. Nothing here is submitted, scored, required for participation, or included in the course grade. Complete as much or as little as is useful.

## How to use this track

Choose one path at a time:

1. **Read:** review the suggested book sections.
2. **Derive:** work through a short calculation on paper.
3. **Experiment:** run or modify a notebook.
4. **Check:** compare your result with the supplied self-check.

The main course remains self-contained. These materials are designed to explain *why* the methods work and connect predictive machine learning with econometric reasoning.
